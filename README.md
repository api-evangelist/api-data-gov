api.data.gov provides a free API management service for United States federal agencies, enabling them to share government data publicly in compliance with the Open Government Data Act. Hosted by GSA’s Technology Transformation Services, it aggregates over 450 APIs across 25 agencies, offering documentation, metrics, and support for developers and agency administrators. The platform aims to simplify data release, improve transparency, and foster innovation through accessible, well‑documented government datasets.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for api.data.gov: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
